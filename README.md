# AI Guardian – Hackathon Project

## About the Project
AI Guardian is a human-controlled safety layer designed to support safer AI agent interactions and personal data protection.

## Key Features
- AI Agent Safety Engine
- Photo Protection Module
- Emergency Stop
- Audit Log
- Interactive Gradio Dashboard

## Technologies Used
Python, Google Colab, Gradio, Pandas, PIL

## How to Run
1. Open the notebook in Google Colab.
2. Run the cells in order.
3. Install any required dependencies.
4. Launch the Gradio dashboard.

## Hackathon Project
Created as part of a hackathon project.
